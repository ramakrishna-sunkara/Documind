INTERNAL DEMO - Model Placement Instructions
============================================

Place the Gemma3 LLM model file in this folder:

File name: gemma3-1b-it-int4.task
Expected size: ~555 MB

Download from: https://www.kaggle.com/models/google/gemma-3/tfLite/gemma3-1b-it-int4

After placing the model here, rebuild the APK.
The app will automatically copy the model to internal storage on first run.

NOTE: The APK size will be ~600MB due to the embedded model.
